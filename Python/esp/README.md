# [ESP for any mob (except babies)](Minescript/Python/esp/radar.py)

### Renders a see through transparent box corresponding to the hitbox of the mob.

Features
* Add multiple unique mobs to render
* Choose the highlighted box color
* Label the mob for better usage idk (it was cool)
* Enable/Disable mobs you want to render
* Remembers what mobs you have added previously

How to use?
1. Download [radar.py](Minescript/Python/esp/radar.py) and [mob_db.json](Minescript/Python/esp/mob_db.json) which is a list of all of the mobs' hitboxes.
2. Type in a mob in the search bar (has to be spelled correctly)

   * or you can click the down arrow to select
3. Add a label name (e.g. Hideonleaf, Pangolin, etc)
4. Add entity
5. The little boxes on the side allow you to disable/enable rendering
6. To edit a mob, its in the same place as where you added a new mob (step 2-4)
